# ⏰ シンプルアラームアプリ

ブラウザで動くシンプルなアラームアプリです。

## 機能

- 現在時刻をリアルタイム表示
- 時刻を指定してアラームをセット
- アラーム時刻になると音で通知
- アラームのクリア機能

## 使い方

1. `index.html` をブラウザで開く
2. アラーム時刻を入力して「セット」ボタンを押す
3. 指定した時刻になると音が鳴る
4. ステータス表示をクリック、または「クリア」ボタンで止める

## ファイル構成

```
simple-alarm-app/
├── index.html   # メインHTML
├── style.css    # スタイル
└── script.js    # アラームのロジック
```
